Red del sistema distribuido

Meseros: hilos en concurrente, procesos en paralelo o nodos en distribuido (hasta 8, como una cafetería real). El secuencial siempre usa 1; si mueves este control estando en secuencial, se cambia a concurrente.

La cafetería

  • Mesa = solicitud de un usuario (aro gris: esperando)
  • Mesero = hilo (proceso en paralelo, nodo en distribuido); su color es el mismo de la línea de tiempo
  • Tapete y pizarra = proceso y su memoria
  • Máquina de café = núcleo físico; cada boquilla = núcleo lógico (Hyper-Threading). Brillo y vapor = uso real
  • Cocina = E/S: esperar sin usar la CPU
  • Caja con candado = recurso compartido con Lock: uno a la vez (tiempo real)
  • Coordinador (rack) = balanceador, dueño del Lock de la caja y reloj de referencia (distribuido)
  • Paquete = mensaje por la red (TCP) entre el coordinador y un nodo
  • Llave dorada = GIL: solo quien la tiene ejecuta Python
  • Taza en la mesa = respuesta entregada
